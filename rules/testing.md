# 测试修改与执行规则

**默认策略：** Agent 可以新增、修改或删除与当前改动直接相关的测试，并可自动运行最窄的相关测试。

1. 优先单文件、单包、单模块或精确筛选的 targeted test；记录命令、退出码和结果。
2. 全套、全模块、仓库根级联或其他广范围测试必须先获得用户确认，不能仅凭命令名称判断范围。
3. 破坏性、生产、付费、外部系统或需要敏感凭据的测试始终先确认；没有安全环境和权限时不得执行。
4. 跳过、不可用或失败的测试必须如实记录；编译、lint、类型检查和静态检查不能冒充测试证据。
5. 测试改动只覆盖获批行为，不扩大产品范围。

若启用 `human-owned-testing` profile，其规则覆盖本默认策略，Agent 不得修改或执行
测试。
