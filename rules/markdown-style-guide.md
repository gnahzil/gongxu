# Markdown 格式规范

> 代码写给人看，顺便让机器运行。Markdown 亦然。

---

## 1. 核心原则

| 原则 | 说明 |
|------|------|
| **源码即文档** | 纯文本状态下也要易读 |
| **一致性优先** | 风格统一比个人偏好重要 |
| **简洁至上** | 能用 Markdown 就不用 HTML |

### 1.1 中文技术写作

- 中文与英文、半角数字之间通常保留一个空格，例如“使用 Redis 处理 3 个任务”；
    代码、路径和标点边界按实际语义处理，不机械插入空格。
- 中文句子使用全角标点；英文句子、代码和命令使用半角标点，标点前不留多余空格。
- API、SDK、CLI、HTTP、Redis 等通用技术术语保留英文；已有稳定中文译名的普通概念
    使用中文，不为追求形式强行翻译或逐项增加中英对照。
- 使用简洁、自然的中文。一句话表达一个主要意思，拆分欧化长句，删除机翻式被动语态、
    冗余代词和宣传性修饰。
- 同一文档中的领域词、产品名、字段名和大小写保持一致；存在项目领域语言时以其为准。

## 2. 文档布局

标准文档结构：

```
# 文档标题（唯一 H1）

引言段落

---

## 1. 第一章节

内容...

## 2. 第二章节

内容...
```

**要点**：

- 单个 H1 作为文档标题
- 引言后用 `---` 分隔（可选）
- 正文从 H2 开始

## 3. 标题规范

### 3.1 使用 ATX 风格

```
# 标题一
## 标题二

❌ 标题一
❌ ========
```

### 3.2 五级标题层级

| 级别 | 用途 | 示例 |
|------|------|------|
| H1 `#` | 文档标题（唯一） | `# 项目指南` |
| H2 `##` | 主章节 | `## 1. 快速开始` |
| H3 `###` | 子章节 | `### 1.1 安装` |
| H4 `####` | 细分内容 | `#### 1.1.1 macOS` |
| H5 `#####` | 补充说明（少用） | `##### 1.1.1.1 注意事项` |

### 3.3 标题编号

**必须**：H2 至 H5 所有标题都要添加数字编号：

```
✅ ## 1. 快速开始
✅ ### 1.1 安装方式
✅ #### 1.1.1 macOS 安装
✅ ##### 1.1.1.1 Homebrew 方式

❌ ## 快速开始（无编号）
❌ **安装方式：**（加粗伪标题）
```

### 3.4 标题格式

```
✅ ## 1. 标题内容

正文...

❌ ##标题内容（# 后无空格）
❌ ## 1. 标题内容：（末尾有冒号）
```

## 4. 段落编号

### 4.1 适用场景

步骤说明、教程内容、流程描述时使用编号段落。

### 4.2 编号格式

**格式**：`数字. 段落内容`

```markdown
1. 第一步：打开终端...

2. 第二步：运行命令...

3. 第三步：验证结果...
```

### 4.3 段落间空行

编号段落之间保留空行，增强可读性：

```markdown
✅
1. 第一段内容较长时...

2. 第二段继续说明...

❌
1. 第一段
2. 第二段（紧挨着，难阅读）
```

## 5. 引用块格式

### 5.1 标准格式

`> emoji **标题**` + 空行 + 内容

```markdown
> 💡 **划重点**
>
> 这是需要强调的核心要点。
```

### 5.2 常用类型

| Emoji | 标题 | 用途 |
|-------|------|------|
| 💡 | 划重点 / 提示 | 核心要点总结 |
| 📌 | 记住这点 | 必须记住的要点 |
| 🎯 | 一句话理解 | 极简概念解释 |
| 💬 | 通俗讲 | 技术名词白话解释 |
| ⚠️ | 重要提示 | 警告信息 |
| 🔧 | 实操技巧 | 操作建议 |

## 6. 列表规范

### 6.1 无序列表

使用 `-` 作为标记（非 `*`）：

```markdown
- 第一项
- 第二项
    - 嵌套项（4 空格缩进）
```

### 6.2 有序列表

短列表用真实编号，长列表可用懒编号：

```markdown
<!-- 短列表 -->
1. 第一步
2. 第二步
3. 第三步

<!-- 长列表（懒编号） -->
1. 第一步
1. 第二步
1. 第三步
```

### 6.3 嵌套缩进

统一使用 4 空格缩进：

```markdown
1. 列表项
    继续内容（4 空格缩进）
    - 嵌套无序
        - 再嵌套
```

## 7. 代码规范

### 7.1 行内代码

用反引号包裹命令、文件名、变量：

```markdown
运行 `npm install` 安装依赖。
修改 `config.json` 文件。
```

### 7.2 代码块

**必须声明语言**：

````markdown
```bash
npm run build  # 构建项目
```

```python
def hello():
    """打印问候语"""
    print("Hello")
```
````

### 7.3 中文注释

代码示例添加中文注释：

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 7.4 禁止缩进式代码块

```
✅ 使用围栏式（```）

❌ 使用 4 空格缩进
```

## 8. 链接规范

### 8.1 信息性标题

```markdown
✅ 参考 [Markdown 指南](https://example.com) 了解更多。

❌ 点击 [这里](https://example.com) 了解更多。
❌ 链接：[https://example.com](https://example.com)
```

### 8.2 引用式链接

长链接或重复链接使用引用式：

```markdown
参考 [官方文档][docs] 和 [API 参考][api]。

[docs]: https://very-long-url.example.com/documentation
[api]: https://very-long-url.example.com/api-reference
```

### 8.3 相对路径

所有仓库内部链接都使用相对于当前文件的路径；跨目录时允许 `../`。禁止机器绝对
路径和站点根路径，因为它们在仓库浏览器、npm 包或 Fork 中不可移植：

```markdown
✅ [相关文档](./related.md)
✅ [其他模块](../other/guide.md)

❌ [机器路径](file:///home/developer/guide.md)
❌ [站点根路径](/docs/other/guide.md)
```

## 9. 表格规范

### 9.1 适用场景

表格适合**表格数据**，不适合长文本：

```markdown
✅ 适合表格
| 命令 | 说明 |
|------|------|
| `dev` | 启动开发 |
| `build` | 构建项目 |

❌ 不适合（用列表替代）
| 功能 | 详细描述...很长很长的文字 |
```

### 9.2 对齐方式

```markdown
| 左对齐 | 居中 | 右对齐 |
|:-------|:----:|-------:|
| 文本   | 文本 | 数字   |
```

## 10. 图片规范

### 10.1 基本语法

```markdown
![图片描述](./images/screenshot.png)
```

### 10.2 Alt 文本

必须提供有意义的描述：

```markdown
✅ ![项目架构图](./arch.png)
❌ ![](./image.png)
❌ ![图片](./image.png)
```

## 11. 格式原则

### 11.1 行宽限制

- 正文：80 字符（软限制）
- 例外：链接、表格、标题、代码块

### 11.2 空行规则

- 标题前后各一空行
- 代码块前后各一空行
- 段落间一空行
- 禁止连续多个空行

### 11.3 无尾空格

禁止行尾空格，换行用 `\`：

```markdown
✅ 需要换行的内容\
   接下一行

❌ 需要换行的内容  （两个空格）
```

### 11.4 优先 Markdown

```
✅ **加粗** / *斜体* / `代码`
❌ <strong>加粗</strong> / <em>斜体</em>
```

### 11.5 块级元素闭合

确保以下元素正确闭合：

| 元素 | 开始 | 结束 | 检查点 |
|------|------|------|--------|
| 代码块 | ` ``` ` | ` ``` ` | 反引号数量一致 |
| 引用块 | `>` | 空行 | 每行都有 `>` |
| 列表 | `- ` 或 `1. ` | 空行 | 缩进对齐 |
| 表格 | `\|` | `\|` | 每行列数一致 |

**常见错误**：

- 代码块缺少结束符 ` ``` `
- 嵌套代码块时反引号数量不匹配（外层用 `````，内层用 ` ``` `）
- 引用块中间意外断开（缺少 `>`）
- 表格行列数不一致

## 12. 文件命名

- 使用小写字母
- 单词间用连字符 `-`
- 扩展名 `.md`

```
✅ api-reference.md
✅ quick-start.md

❌ API_Reference.md
❌ QuickStart.MD
```
