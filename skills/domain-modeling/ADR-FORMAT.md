# ADR 格式

ADR 默认写入 `docs/agent/adr/NNNN-<slug>.md`，编号取现有最大值加一。目录只在首个 ADR 经用户批准后创建。

```markdown
# <简短决定标题>

> 状态：已接受

<用一至三段说明背景、最终决定和选择它的原因。>
```

仅在确有价值时追加：

- `考虑过的方案`：被拒绝方案值得未来继续了解时添加。
- `影响`：存在不明显的长期代价时添加。
- `替代 / 废弃`：决定被新 ADR 取代时，链接新的 ADR，不改写历史。

不要为同一需求的每个实现选择建立 ADR；普通方案细节留在当前子 Spec 的
`state.md` Decisions。
