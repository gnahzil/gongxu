# 领域语言格式

领域语言默认写入 `docs/agent/domain-language.md`。文件不存在时，在首个规范术语经用户批准后按需创建。

```markdown
# 领域语言

## <上下文名称>

<一两句话说明该业务上下文负责什么、不负责什么。>

### 术语

**<规范术语>**

<用一两句话定义它是什么。>

- 避免：`<同义词>`、`<含糊词>`
- 归属：`<拥有该概念的业务上下文>`
```

## 规则

- 只记录项目特有的业务概念；通用技术名词不进入本文档。
- 一个概念只选一个规范名称，其他名称进入“避免”。
- 定义说明“是什么”和业务边界，不描述类名、表名、接口或实现流程。
- 单文件按上下文分节；接近项目文件规模上限时再拆分，并同步项目 `AGENTS.md` 指针。
